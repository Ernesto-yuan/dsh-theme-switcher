# 个性化 / Personalization

给 DeepSeek Harness 加一个「个性化」设置页：20 套明暗配色（含渐变与彩虹）+ 高级材质（毛玻璃）。

## 功能

- 20 套配色：北境、日光、樱花、薰衣草、森林、石墨、深海、午夜、日落、咖啡、青瓷、红玉、晴空、极光、沙丘，再加 5 套渐变主题——草莓牛奶、薄荷苏打、香芋奶盖、柠檬气泡、彩虹，外加「默认」回到原生配色；每套都有浅色与深色两版，跟随「外观」里的浅色 / 深色 / 跟随系统。
- 渐变主题：页面底层铺多层径向渐变叠加出来的柔和色块（不是一条直线式的渐变），面板与侧栏是半透明的，让渐变透出来；文字与边框仍是纯色，保证可读。
- 高级材质：半透明面板与背景模糊，作用在菜单、弹层、提示气泡、弹窗遮罩和输入框卡片上。
- 调色盘：自定义纯色背景（取色器直接选色），或自定义两色渐变（起止色 + 角度 0–360）。
- 自定义 Emoji：输入或粘贴任意几个 Emoji（最多 12 个），插件会在本地把它画成一张 1024 的贴图当背景，不用等预设。
- 背景：8 套 Emoji 背景（甜心、夏日、森林、夜空、彩虹、派对、黄脸、表情）一键切换，图案是 1024 像素的贴图、按 512 像素铺在页面上（高分屏下 2 倍像素密度，看着更清晰）；也可以选本地图片当背景，长边自动缩到 1920 像素后存本地。卡片与侧栏会变成半透明让背景透出来，同时保留当前配色自己的色相——换主题时底色跟着变，不会永远是白色；可随时清除。背景只存在浏览器 localStorage 里，刷新后还在，不会上传。
- 中英双语，界面全部使用宿主主题 token，随主题换色。
- 叠加渐变：背景区多一个开关，打开后当前配色的渐变压在背景上（soft-light 混合），两个功能可以同时用；关掉只显示背景，纯色主题下开关不产生渐变。
- 左侧边栏固定入口：个性化同时是一个独立页面，侧边栏里有调色盘图标，点开就是同一套设置，不用先进设置页。
- 选择保存在浏览器本地，刷新后保留。

## 安装

需要包含 `settings.section` 与 theme 服务的 DSH 版本（已在 0.2.1-rc.3 验证）。

方式一（推荐，保持可升级）：

```bash
dsh plugin --profile <你的 profile> add <本文件所在目录或 tgz 路径>
```

方式二：在 DSH 会话里让 Agent 用平台安装入口安装本目录：

```
plugin_manager install_bundle <本目录绝对路径>
```

安装后重启 DSH（或在设置 → 插件里确认已启用）。

## 使用

设置 → 个性化。

- 顶部开关「高级材质」：打开后菜单、弹窗、输入框卡片呈现毛玻璃。
- 下面网格选择配色；「默认」回到 DSH 原生配色。

## 说明

- 只改外观，不收集数据、不发网络请求。
- 渐变主题通过一条额外样式把 body 的背景改成渐变，并给面板留了透明度；如果宿主以后把页面底色画到别的容器上，这一层可能需要跟着改选择器。
- 高级材质依赖浏览器的 `backdrop-filter`；纯色平面背后没有内容可模糊，所以在侧栏、消息区这类背景上观感变化很小。
- 卸载：从 profile 移除本 bundle，或在设置 → 插件里停用。
