# 个性化 / Personalization

给 DSH 加一个「个性化」页，同时固定在左侧边栏：配色、渐变、Emoji 与图片背景、毛玻璃，全部只存在浏览器本地。首个正式版 1.0.0。

## 模块

### 1. 配色主题

- 20 套明暗配色，外加「默认」回到 DSH 原生配色：
  - 纯色 15 套：北境、日光、樱花、薰衣草、森林、石墨、深海、午夜、日落、咖啡、青瓷、红玉、晴空、极光、沙丘
  - 渐变 5 套：草莓牛奶、薄荷苏打、香芋奶盖、柠檬气泡、彩虹
- 每套都有浅色与深色两版，跟随「外观」里的浅色 / 深色 / 跟随系统。
- 渐变主题是 4–6 层径向色团叠出来的柔和色块，不是一条直线式渐变；页面与侧栏透明，让渐变色透出来，文字与边框保持纯色。
- 选择保存在浏览器本地，刷新后保留。

### 2. 自定义背景

四种背景类型，都在「自定义背景」表单里创建：

| 类型 | 说明 |
|---|---|
| Emoji 组合 | 输入或粘贴最多 12 个 Emoji，本地渲染成 1024 像素贴图；每个 Emoji 大小、角度、位置随机错开，同一组每次结果一致 |
| 纯色 | 取色器直接选色，铺满整页 |
| 渐变 | 默认两个颜色，可加到 5 个；每个颜色单独取色、可移除；角度 0–360。渲染成柔和无规则的径向色团（参考彩虹主题），角度会旋转色团位置 |
| 图片 | 选本地图片，长边缩到 1920 像素、转 JPEG 后保存，不超过 10 MB 上限时自动裁剪 |

内置 8 套 Emoji 背景（甜心、夏日、森林、夜空、彩虹、派对、黄脸、表情）是固定的，只读，不能改名也不能删除。自定义的四种类型都可以保存、改名、删除。

### 3. 我的背景

- 创建时先填名称（留空自动叫「自定义 N」），再点【保存并应用】。
- 保存后按类型显示缩略图：Emoji 与图片整图铺满卡片；纯色与渐变显示成主题卡式预览（左侧背景条 + 右侧文字线与色点）。
- 点缩略图切换背景；点 ✎ 改名（回车保存、Esc 取消、空名忽略）；点 × 删除。
- 删除的正好是当前背景时，页面回到无背景状态。
- 最多 12 个，存在浏览器本地，刷新后保留。

### 4. 叠加渐变

- 开关打开时，图片/Emoji 铺满页面当背景，当前配色的渐变原样作为一层 50% 不透明度的滤镜盖在上面（颜色与配色本身不变），两个功能可以同时用。
- 对纯色和自定义渐变背景不生效——它们本身没有照片层可混合。
- 关掉只显示背景本身。

### 5. 高级材质

- 半透明面板配背景模糊，作用在菜单、弹层、提示气泡、弹窗遮罩与输入框卡片上。
- 依赖浏览器 `backdrop-filter`；纯色平面背后没有内容可模糊，所以在纯色区域观感变化很小。

### 6. 侧边栏入口

- 个性化同时是一个独立主面板，左侧栏有调色盘图标（位置在插件市场与自动化任务之间）。
- 点图标打开独立页面，内容和设置页一致，改的是同一份状态。
- 这一行和其他面板一样可以在「更多」里取消固定或加回来。

## 安装

需要包含 `settings.section`、`main` 与 theme 服务的 DSH 版本（已在 0.2.2-rc.1 验证）。

从 npm 安装：

```bash
dsh plugin --profile <你的 profile> add dsh-theme-switcher
```

直接从仓库安装：

```bash
dsh plugin --profile <你的 profile> add github:Ernesto-yuan/dsh-theme-switcher
```

或下载 Release 里的 tgz：

```bash
dsh plugin --profile <你的 profile> add <tgz 文件路径>
```

装完在 设置 → 插件 里确认已启用；客户端代码首次加载需要刷新一次页面。

## 使用路径

- 设置 → 个性化
- 或点左侧栏的调色盘图标

## 兼容性与限制

- 只改外观：不写文件、不发网络请求，所有选择都存在浏览器 localStorage。
- 依赖 DSH 主题 token（`--dsw-alias-*` 与 `--dsw-specific-*`），宿主把底色画到别的容器上时需要同步调整选择器。
- 渐变主题与背景都通过 `body` 背景实现；毛玻璃依赖 `backdrop-filter`。
- 背景图片与自定义 Emoji 贴图都以 data URL 存储，图片过大时会提示换一张。
